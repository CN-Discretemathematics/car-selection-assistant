# 记忆的边际价值：合成会话上的 on/off 对照（2026-10-21）

> 工具：`backend/tools/eval_memory_value.py`｜题库：`backend/tools/gen_multiturn_scenarios.py`
> 数据源：本地合成会话（`backend/.tmp/eval-local.db` 快照 + 200 题多轮题库）

## 一、它回答哪条判断

计划 §七的第一条未验证判断：

> 「硬约束排除项是记忆的第一价值」——产品直觉，未做用户测试。

这条判断**至今没有任何数据**。本文件给它加一层**机制层**证据：
同一批跨会话场景，**记忆开**（`DURABLE_PREFS_MODE=on`）与**记忆关**（`off`）各跑一遍，
比较通过率（= 1 − 违规率）的差。

## 二、方法

| 项 | 做法 |
| --- | --- |
| 场景 | 200 题多轮题库里的**三类跨会话记忆**场景，各 50 题（共 150 题 × 2 组 = 300 次运行） |
| 两组 | 同一进程内切换 `DURABLE_PREFS_MODE`（`get_mode()` 每次调用现读环境变量） |
| 隔离 | 每个场景新建一个匿名身份 ⇒ **on 组写下的记忆不会漏进 off 组** |
| 判据 | 每类场景的通过率（on vs off）与差值 Δ |
| 空转防护 | `off` 组若也 100% 通过 ⇒ 该类**不构成对照**（断言恒真），报告里单独标出，不计入「有效」 |

## 三、实测数字（本机真跑）

| 记忆类型 | 场景数 | on 通过 | off 通过 | Δ | 判定 |
| --- | --- | --- | --- | --- | --- |
| 预算（回访记忆生效） | 50 | **50/50** | **0/50** | +100.00% | 记忆有效 |
| 预算（记忆删除后不生效） | 50 | **50/50** | **0/50** | +100.00% | 记忆有效 |
| 拒绝/排除（跨会话还记得） | 50 | **50/50** | **0/50** | +100.00% | 记忆有效 |

**off 组全红这件事本身就是结论**：它证明这些断言**不是「本来就过」**——
把记忆功能整体关掉，跨会话记忆确实**全部失效**（0/50）。
（这正是本仓反复记录的恒真陷阱：记忆删除场景曾经「记忆功能关闭时照样 50/50 通过 ⇒
验不到任何东西」，后来补了阳性对照轮才作数。）

## 四、结论（诚实版）

1. **机制上三类记忆都有效**：关掉就全错，开着就全对（Δ = +100%）。
2. **但三类完全等价** ⇒ 这套**二元**指标**无法给记忆类型排序**。
   「排除项是记忆的第一价值」在合成会话上**得不到支持**（也不被推翻）——
   它仍然是一条**未验证的产品判断**，本文件没有把它变成已验证。
3. **要回答它，题库得先补一类场景**：现有跨会话题库覆盖的是
   **预算**（回访生效、删除后不生效）与**拒绝**（跨会话还记得）——
   而「排除项」里的**品牌排除 / 车系排除**（`avoid` / `brand_exclude`）
   **没有评测级覆盖**。§七 那条判断指的正是后者。
   ⇒ **待办**：加一类「排除项跨会话记住」场景（用户说「不要 X 品牌」→ 换会话 → 它不再出现），
   断言要查**结构化推荐结果里的品牌**，不能查正文裸字符串。
4. **真实用户验证仍然缺**：本文件是**机制层**证据，不是用户价值证据。
   2026-10-21 实测生产：`agent_turn_logs` **0 行**；近 14 天 nginx **43,660** 条请求里
   agent 端点只有 `GET /api/v1/agent/sessions`，**消息 POST 次数为 0**
   ⇒ 生产至今没有过一次真实对话，「真实用户测试」这个最终判据当前无从谈起。

## 五、复现

```bash
cd backend
export DATABASE_URL="sqlite:///.tmp/eval-local.db"
export RETRIEVAL_BACKEND=inmemory
python tools/gen_multiturn_scenarios.py --out .tmp/corpus.json --enable-memory-scenarios
python tools/eval_memory_value.py --scenarios .tmp/corpus.json --report .tmp/memory_value.json
```
